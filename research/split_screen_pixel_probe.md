# Narrow split-screen acquisition test
This supplements LiveCaptureProbe, which logs track state but never checks pixels. Serve the research directory locally on a secure context, open split_screen_pixel_probe.html, open the separate synthetic target, then explicitly select only that target via the browser capture picker within 120 seconds. No payment, banking app, notification contents, PIN, screenshots or transmission. A positive result establishes acquisition of the synthetic selected surface only, not access to PhonePe, Google Pay, financial notifications or payment status. Negative results distinguish absent API, denied capture, expired window and missing marker. The automated tests use synthetic pixels. Real-device results are not yet recorded. This isolated page is not part of the customer checkout; existing production remains unchanged. Standard service-worker notifications only expose current-origin notifications (MDN getNotifications). Chrome Android screen capture is not supported in current compatibility data. No permission bypass or financial verdict.

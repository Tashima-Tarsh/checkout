# MyUPI evidence interface (offline)
The manually viewed historical debit screenshot establishes display availability of direction, successful status, amount, date/time, twelve-digit transaction ID, debit bank, beneficiary bank and masked beneficiary account suffix, payment mode and app. It does not establish a receiving-account credit schema, automated access permission, independently verifiable provenance, or a fresh checkout match. No actual transaction identifiers are committed.

The new adapter defaults to disabled. A future authorized source must implement EvidenceSource using a permitted interface and independently establish account binding and source authenticity. No browser session export, undocumented endpoints or credential capture is implemented. Existing n8n dispatch remains unchanged and returns PENDING. Candidate matching cannot establish financial verification. Do not connect fixtures to production. Before live integration, obtain provider authorization and verify real incoming field availability and source proof.

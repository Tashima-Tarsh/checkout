# Customer checkout receipt indicator
Customer checkout never renders a manual upload control, vision lab heading, or diagnostic controls. The separate merchant-authorized /checkout/<id>/vision page remains available for explicit research tests.
On initial checkout and on a browser return, the customer UI renders a green tick and "Receipt recognized" only when the server returns a scoped receipt_observation object with order_id matching the current checkout, decision VISUAL_SUCCESS, advance_research true, financially_verified false and checkout_changed false. Otherwise no tick is rendered. Existing checkout state remains independent; no Payment Done claim is made. Current backend checkout_info does not publish receipt_observation; the interface is reserved for a future authorized acquisition integration. The Chromium test mocks a server response to exercise the presentation; it does not prove receipt acquisition. No capture permission or hidden image collection is added.

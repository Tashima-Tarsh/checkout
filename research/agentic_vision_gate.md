# Agentic Vision Payment Gate (research)
Enable AGENTIC_VISION_LAB=1 in the Agentic Pay service. Sign in as the merchant that owns a checkout and open /checkout/<order-id>/vision. Select an existing authorized PNG/JPEG/WebP receipt and press Analyze payment image. Local Tesseract recognizes the success heading and amount; only the research gate advances. Negative, uncertain and mismatched images stay blocked. Images and OCR text are not stored or returned. No external OCR provider, payment POST, order state change, merchant fulfillment, or financial verification occurs. A fabricated image can pass the visual gate; it is not debit evidence. The automatic acquisition adapter is intentionally not implemented in this stage. No real customer receipt is committed. Tests create synthetic images. The lab is disabled by default and merchant-scoped, with bounded image size, pixel count, worker concurrency and OCR timeout. Ordinary checkout remains unchanged. No deployment requested.

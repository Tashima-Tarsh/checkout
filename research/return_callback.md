# Checkout return callback
After a successful Copy UPI ID, the checkout arms a one-shot callback for five minutes. A hidden-to-visible transition or a visible blur-to-focus transition triggers a same-origin GET of the current checkout. It displays a return message or existing PENDING status. No payment provider callback, automatic payment claim, POST, screenshot, third-party app data, or diagnostic upload occurs. Manual I Paid disarms the callback. Reloading discards the in-memory arm. Android split-screen is user-controlled. The 3.5s hidden / 41.8s visible user-reported physical trace is replayed in a unit test without identifiers. Chromium integration uses a synthetic fixture and synthetic focus events. Physical device callback behavior after deployment remains to be tested.
